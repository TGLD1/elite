Page Web, Site Web, Développement Web

Jusqu'à présent, plusieurs termes ont peut-être été lancés, comme site web, page web, développement web, développeur web, etc. Que signifient-ils exactement ? Qu'est-ce qu'un site web, techniquement ? Et que désigne exactement le développement web ?

Répondons à ces questions maintenant !

✕

Page Web ou Site Web

Un site web, comme son nom l'indique, est un site sur le Web. Ici, le Web désigne le réseau/Internet. Tout comme un terrain sur lequel on construit sa maison, un site web est un emplacement sur un serveur réseau où vous pouvez stocker votre contenu.

En dehors de cela, techniquement parlant, un site web est une collection de pages web publiées sur un serveur web et accessibles via un réseau/Internet en utilisant l'adresse du site.

En termes simples, un site web est une collection de pages web. Les pages web sont des pages en ligne que vous pouvez consulter en utilisant Internet et le service Web sur un ordinateur ou un smartphone.

✕

Qu'est-ce que le développement web ?

Le développement web, également connu sous le nom de développement de sites web, fait référence aux tâches associées à la création, la construction et la maintenance de sites web et d'applications web qui fonctionnent en ligne sur un navigateur.

Il est étroitement lié au travail de conception des fonctionnalités et de la logique des applications web. Le terme développement est généralement réservé à la construction effective de ces choses, c'est-à-dire la programmation des sites.

✕

Cela se fait en écrivant des lignes de code, en utilisant une variété de langages de programmation, qui varient en fonction des tâches à effectuer et des plateformes sur lesquelles ils travaillent.

✕

Conclusion

Pour conclure, un site web, au cœur de son essence, n'est qu'un moyen de collecter et d'afficher publiquement des informations. Quelle que soit la complexité d'un site web, tout se résume à cet objectif fondamental.

En avançant, nous examinerons les différentes technologies utilisées pour développer les pages web et les applications web.
