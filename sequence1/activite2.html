Le Web

Le réseau Internet fait partie intégrante et de plus en plus importante de la vie quotidienne des personnes à travers le monde. C'est ce réseau qui rend le Web possible. Sans Internet, le Web ne peut tout simplement pas exister !

Internet est un réseau mondial composé de milliards d'ordinateurs et d'autres appareils électroniques. Vous pouvez le considérer comme un système mondial de réseaux informatiques, également appelé un réseau de réseaux, où chaque réseau est un nœud.

✕
Le Web
Internet = Interconnecté + Réseau

Salut l'ami ! Bienvenue dans toute première section de ton parcours de développement web. Dans cette section, nous allons rapidement comprendre quelques concepts avant de se plonger réellement dans le développement web.

Comprendre le Web

Vous pourriez penser que les termes « Web » et « Internet » sont interchangeables. Mais sont-ils vraiment identiques ? Bien sûr que non !

Internet est une infrastructure qui permet de connecter des milliards d'ordinateurs. Parmi eux, certains ordinateurs, également appelés serveurs Web, peuvent envoyer des messages compréhensibles aux navigateurs Web.

Par conséquent, on peut considérer Internet comme une infrastructure, tandis que le Web est un service construit au-dessus de cette infrastructure.

✕

Internet et le Web

Considérez l'analogie ci-dessous pour comprendre la différence entre l'Internet et le Web en termes très simples.

Analogie : Vous pouvez considérer l'Internet comme l'électricité, les voies ferrées comme le Web, les trains qui vont d'une destination à l'autre comme les Données, et les quais comme le navigateur Web.

✕

WWWW

Les deux écrans précédents vous ont donné un aperçu de l'idée sur laquelle repose le Web. Mais, qu'est-ce que le Web exactement ?

Le Web est le nom courant du célèbre acronyme WWW, qui signifie simplement World Wide Web. Le WWW est un sous-ensemble de l'Internet composé de pages qu'un navigateur Web peut consulter. En termes simples, il s'agit d'un système interconnecté de pages Web publiques accessibles via Internet.

✕

Le Web est l'une des nombreuses applications construites au-dessus d'Internet.

✕

En savoir plus sur le WWWW

Le World Wide Web est l'univers des informations accessibles en réseau, une incarnation du savoir humain. C'est un moyen d'échanger des informations entre ordinateurs sur Internet, en les reliant en une vaste collection de ressources multimédias interactives.

À l'époque, Tim Berners-Lee a proposé l'architecture de ce qui est devenu le World Wide Web tel que nous le connaissons aujourd'hui.

✕

Il a créé le premier serveur Web, le premier navigateur Web et la première page Web sur son ordinateur au Laboratoire de recherche en physique du CERN en 1990. Un an plus tard, il a annoncé sa création sur le groupe de discussion « alt.hypertext », marquant le moment où le Web a été rendu public pour la première fois.
