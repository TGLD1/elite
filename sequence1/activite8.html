Activité 8 : Votre première page Web

Travaillons avec le HTML !

Le HTML est la base de tous les sites Web et représente le strict minimum nécessaire pour créer un site Web. C'est un langage qui dit aux navigateurs Web comment structurer les pages Web que vous visitez, qui peuvent être aussi compliquées ou aussi simples que le développeur Web le souhaite.

Il est temps de mettre la main à la pâte avec le HTML et de créer votre première page Web !

Créer votre première page Web est aussi simple que de créer un fichier HTML et de le charger dans un navigateur. Voyons comment vous pouvez faire cela...

Les fichiers HTML ne sont rien d'autre que de simples fichiers texte. Donc, pour commencer à écrire en HTML, vous n'avez besoin de rien de plus qu'un simple éditeur de texte. Par conséquent, vous pouvez utiliser le Bloc-notes (Notepad) ou TextEdit selon votre système d'exploitation Windows ou macOS.

1. Créez un dossier, de préférence sur votre Bureau, et nommez-le 'htmlFiles'.

2. Ouvrez votre éditeur de texte et enregistrez un fichier vide sous le nom 'myFirstWebPage.html' dans ce dossier.

C'est votre premier document HTML ! De plus, votre première page Web est également prête, ce qui est certes une page Web vide pour le moment.

Note : Assurez-vous d'ajouter '.html' au nom du fichier. L'extension .html est l'extension de fichier pour un document HTML, tout comme .txt l'est pour un document texte.

Il est temps de charger la page sur le Web et de visualiser votre document HTML sur le Web !

Eh bien, pour visualiser les documents HTML, ils n'ont même pas besoin d'être sur le Web. Vous pouvez simplement ouvrir un navigateur Web tel que Chrome, Firefox, Safari ou Internet Explorer, et dans la barre d'adresse (où vous tapez habituellement les adresses Web), tapez l'emplacement du fichier que vous venez d'enregistrer (par exemple, 'C:/Users/John/Desktop/htmlFiles/myFirstWebPage.html') et appuyez sur Entrée (Enter).

Autrement, allez dans le dossier où vous avez enregistré le document et double-cliquez sur le document HTML.

Votre page Web devrait ressembler à celle de l'illustration ci-dessus ! La voilà, votre première page Web. Comme c'est excitant !! Tout ce qu'il a fallu, c'est la création d'un fichier HTML.

Passer à la suite

Soyez fier et sautez de joie ! Vous venez de créer votre première page Web et avez fait vos premiers pas pour devenir un développeur Web. 💪

Certes, la page Web ne ressemble pas à celle dont vous avez peut-être rêvé, mais elle prendra lentement forme au fur et à mesure que vous apprendrez le HTML et structurerez la page Web.
