Activité 7 : Un regard approfondi sur le HTML

Le cœur du Web

Le HTML est le langage central du World Wide Web et a été initialement conçu comme un langage pour décrire sémantiquement des documents scientifiques. Cependant, il s'est désormais adapté pour décrire la structure de base des pages Web et des applications en ligne.

C'est un langage qui dit aux navigateurs Web comment structurer les pages Web que vous visitez, qui peuvent être aussi compliquées ou aussi simples que le développeur Web le souhaite.

Précédent Suivant

De plus, c'est la donnée brute à partir de laquelle une page Web est construite. Tout le texte, les liens, les cartes, les listes, les boutons ou tous les autres éléments visuels que vous voyez sur la page Web sont créés en HTML.

En termes simples, HTML met des informations sur une page Web !

HyperText et Balisage !

Décomposons l'acronyme HTML et comprenons-le mieux :

1. HyperText : Le terme "HyperText" fait référence à la façon dont les pages Web (documents HTML) sont liées entre elles. C'est simplement le texte organisé pour connecter des éléments connexes, permettant aux visiteurs de cliquer et d'aller vers une autre page ou une autre partie de la page.

Lier des informations de cette manière a révolutionné le Web. Ainsi, ensemble, HTML et Internet permettent à quiconque d'accéder à tous les types d'informations dans le monde, dans l'ordre qu'il souhaite.

Précédent Suivant

2. Markup (Balisage) : Le balisage est un guide de style pour composer tout ce qui se trouve sur une page Web. Il définit des annotations dans le fichier HTML qui ne sont pas affichées sur la page Web elle-même, mais qui agissent en coulisses pour dire aux navigateurs comment afficher le document aux visiteurs.

3. Language : Enfin, c'est un langage que le Web comprend et qui peut être utilisé pour interagir avec lui.

Simple ? C'est le HTML...

Un peu d'histoire

Waouh ! Il semble que vous connaissiez bien le HTML maintenant ! Avant d'avancer, jetons un coup d'œil rapide au parcours du HTML.

Le HTML a été présenté pour la première fois par Tim Berners-Lee, le créateur du World Wide Web, en 1989.

En remontant quelques années auparavant, en 1980, le physicien Tim Berners-Lee a eu l'idée d'un système dans lequel les documents pouvaient être stockés et partagés avec les chercheurs du CERN.

Précédent Suivant

Les documents seraient stockés sur un serveur et les chercheurs pourraient y accéder via un navigateur Web.

Par conséquent, il a créé le Web à l'origine pour permettre aux physiciens de collaborer et de partager leurs travaux entre eux.

Un peu d'histoire

En 1989, il a composé une mise à jour proposant un Système Hypertexte basé sur Internet pour les ordinateurs mondiaux. L'idée de Tim Berners-Lee était un modèle dans lequel les utilisateurs peuvent naviguer d'un ensemble d'informations sur un ordinateur à un autre ensemble d'informations sur un autre ordinateur.

C'est ainsi que le HTML est né... 🎉

Est-ce un langage de programmation ?

Le HTML est généralement désigné comme un langage de balisage ! Cela signifie-t-il que ce n'est pas un langage de programmation ?

Le débat pour savoir si le HTML est ou non un langage de programmation est un débat permanent parmi les développeurs Web et les experts. Eh bien, si vous voulez être technique, le HTML n'est pas un langage de programmation car il ne se préoccupe que de présenter l'information.

Il n'est pas utilisé pour programmer une quelconque logique !

Précédent Suivant

Un langage est qualifié de langage de programmation lorsqu'il exécute des fonctions, effectue des tâches, travaille avec de la logique, etc. Alors que le HTML ne fait vraiment rien. Il donne simplement aux navigateurs le contenu dont ils ont besoin pour afficher.

Mais laissons les experts débattre de cette question pendant que nous l'apprenons, indépendamment de son titre de "langage de programmation" ou non.
