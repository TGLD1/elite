Éditeur de texte

Un éditeur de texte est un logiciel informatique utilisé pour éditer du texte brut. Il se distingue d'un traitement de texte car il ne gère pas le formatage de documents ou d'autres fonctionnalités couramment utilisées en PAO (publication assistée par ordinateur).

Pour commencer le développement web, avoir accès à un éditeur de texte peut être bénéfique pour écrire du code basique. Vous avez probablement déjà un éditeur de texte basique sur votre ordinateur. Par défaut, Windows inclut le Bloc-notes (Notepad) et macOS est livré avec TextEdit.

Précédent Suivant

Comme nous l'avons vu, vous pouvez utiliser un éditeur de texte pour écrire du code web basique. Cependant, à mesure que la longueur et la complexité du code augmentent, il est préférable de passer à un éditeur de code qui est spécialisé à cet effet.

Vous pouvez utiliser Visual Studio (VS) Code, qui est un éditeur de code source gratuit créé par Microsoft pour Windows, Linux et macOS. Il inclut la prise en charge du débogage, de la coloration syntaxique, de l'auto-complétion intelligente, d'extraits de code, de la refactorisation de code et de Git intégré.

De plus, vous pouvez utiliser tout autre éditeur de code que vous connaissez, comme Atom, Sublime Text, ou d'autres. Nous utiliserons VS Code pour l'ensemble de la série de cours sur le développement web.

Le Navigateur Web

Un navigateur web est l'outil le plus important pour les développeurs web. Il est tout simplement indispensable pour de nombreuses tâches, de la recherche sur le Web au débogage de scripts. De plus, vous verrez le résultat de votre code dans un navigateur, puisque vous développez une application web.

Par conséquent, avoir accès à un navigateur compatible, rapide et offrant des tonnes d'outils pour les développeurs web est un must. Probablement, tous les systèmes sont livrés avec un navigateur web par défaut, mais nous vous recommandons d'utiliser Google Chrome.

Si vous n'avez pas Chrome installé, vous pouvez le télécharger ici -
https://www.google.com/intl/en_in/chrome/
