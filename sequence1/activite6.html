Activité 6 : Rencontrez le HTML

Les ordinateurs ne comprennent pas la langue que nous parlons (l'anglais), et nous ne parlons pas la langue qu'ils comprennent (le langage binaire). Par conséquent, nous devons apprendre des langages et des techniques que les humains et les ordinateurs comprennent.

Ainsi, nous pouvons faire faire aux ordinateurs des choses et exécuter des tâches en écrivant un programme pour eux en utilisant divers langages de programmation. Les langages de programmation sont les langages que les ordinateurs comprennent et que nous pouvons apprendre, nous permettant ainsi de communiquer avec ces machines.

C'est ce qu'on appelle le Codage / la Programmation.

Pour conclure, la programmation est la séquence d'étapes d'instructions que nous écrivons pour l'ordinateur afin qu'il puisse comprendre et effectuer certaines tâches pour nous !

Précédent Suivant

Vous connaissez peut-être divers langages de programmation tels que Java, Python, C, et bien d'autres, qui vous permettent d'écrire des programmes informatiques et peuvent être utilisés pour le développement de logiciels, ainsi que pour de nombreux autres cas d'utilisation.

Maintenant que nous comprenons que la programmation est la séquence d'instructions que nous écrivons pour l'ordinateur afin qu'il puisse comprendre et effectuer des tâches pour nous. Et si la tâche consistait à interagir avec Internet et à créer une page Web ?

Voici l'arrivée des langages de balisage !

Précédent Suivant

Les langages de balisage sont des langages qui peuvent être utilisés pour créer divers documents pouvant être chargés dans un navigateur Web via Internet, vous aidant ainsi à interagir avec le Web et à développer diverses pages Web.

Ce n'est peut-être pas une définition parfaite et technique des langages de balisage, mais elle suffit pour vous donner un avant-goût de ce que sont exactement ces langages.

L'un de ces langages de balisage est le HTML, que nous allons apprendre dans ce cours et qui vous permettra de créer des pages Web et de travailler sur le Web.

Précédent Suivant

Le langage du Web - HTML

HTML signifie HyperText Markup Language (Langage de balisage hypertexte) !

C'est la fondation de tous les sites Web et représente le strict minimum nécessaire pour créer un site Web. Selon les statistiques, environ 94 % des sites Web actuellement disponibles sur Internet, et probablement tous ceux que vous visitez, sont structurés à l'aide du HTML.

Précédent Suivant

Au niveau le plus basique, c'est un langage de balisage pour le Web qui définit la structure du Web et constitue l'un des éléments de base les plus fondamentaux de chaque site Web. Gardant cela à l'esprit, nous examinerons le HTML plus en profondeur dans la section suivante.
