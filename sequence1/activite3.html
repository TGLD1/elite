Activité 3 : Comprendre le fonctionnement du Web

✕

Plongée plus profonde dans le Web

Le Web est un moyen d'échanger des informations entre ordinateurs sur Internet, les reliant en une vaste collection de ressources multimédias interactives.

Vous cliquez sur les petits mots bleus soulignés, vous cherchez sur Google le sens d'un mot comme "éthéré", vous tapez l'adresse www.quelque-chose, et vous vous retrouvez à regarder des photos de chats. C'est ainsi qu'un site web fonctionne, n'est-ce pas ? Bien sûr, ce n'est pas aussi simple !

✕

Comment ça marche ?

Considérez le service de livraison de pizza de Domino's comme le Web. D'un côté de la ville se trouve le client, qui est comme votre maison où vous voulez que la pizza soit livrée, et de l'autre côté de la ville se trouve le serveur, qui est le magasin Domino's où vous voulez commander la pizza.

✕

Avant de discuter du flux complet du fonctionnement du Web, jetons rapidement un coup d'œil à quelques terminologies et essayons de les intégrer dans cette analogie :

Internet : Cela vous permet d'envoyer et de recevoir des données sur le web. C'est fondamentalement comme les routes entre votre maison et le magasin de pizzas qui permettent la livraison de la pizza.

TCP/IP : TCP/IP sont des protocoles de communication qui définissent comment les données doivent voyager sur Internet. C'est comme le mécanisme de transport qui vous aidera à récupérer la pizza du magasin Domino's. Dans ce cas, il peut s'agir du livreur de pizzas.

Suite à l'écran suivant...

✕

DNS : Le DNS (Domain Name System) est comme un répertoire d'adresses pour les sites Web. Le navigateur doit trouver sur quel serveur se trouve le site Web, afin de pouvoir envoyer des messages HTTP (Hypertext Transfer Protocol) au bon endroit. C'est comme chercher les pizzas disponibles dans le magasin.

HTTP : C'est un protocole d'application qui définit un langage pour que les clients et les serveurs puissent se parler. C'est comme le langage que vous utiliserez pour commander votre pizza.

Fichiers : Un site Web est composé de nombreux fichiers différents, qui sont comme les différents ingrédients avec lesquels la pizza est faite. Principalement, ces fichiers existent sous les deux types suivants : les fichiers de code et les fichiers de ressources (assets).

Maintenant que les terminologies ci-dessus et leur rôle sont clairs, dans les prochains écrans, nous examinerons le flux global.

✕

Le flux global

Maintenant, regardons le flux de la façon dont vous demandez quelque chose sur le Web et le processus qui est suivi pour le délivrer.

Une fois que vous tapez l'adresse Web dans votre navigateur (c'est comme passer une commande de pizza chez Domino's), le processus ci-dessous est lancé :

1. Le navigateur récupère l'adresse réelle du serveur où le site Web se trouve à partir du serveur DNS. C'est comme choisir la pizza requise parmi celles disponibles au magasin de pizzas.

✕

2. Ensuite, le navigateur envoie un message de requête HTTP au serveur, lui demandant d'envoyer une copie du site Web au client. Ce message et toutes les autres données envoyées entre le client et le serveur sont transmis via votre connexion Internet en utilisant TCP/IP. C'est comme le livreur qui récupère la pizza au magasin.

Appuyez sur 'Suivant' pour continuer...

✕

Suite...

3. Si le serveur approuve la demande du client, le serveur envoie au client un message '200 OK'. Cela signifie simplement que vous pouvez accéder à la page Web, puis le serveur commence à envoyer de petits morceaux de données de la page Web au client. Cette étape est exactement comme le magasin de pizzas qui confirme les détails de la commande avec le livreur et lui remet la pizza.

4. Enfin, le navigateur assemble les petits morceaux de données en une page Web complète et vous l'affiche. Tout comme lorsque la pizza arrive à votre porte pour être savourée !

C'est tout ! Voici comment fonctionne le WEB.
